Problem 1 — Match Winner
Function Name Must be: matchWinner
The 2026 FIFA World Cup Group Stage is underway. Create a function that determines the match result from Team A and Team B goals.
Input: teamAGoals, teamBGoals.
Rules: Return 'Team A Won', 'Team B Won', or 'Draw'. Return 'Invalid' if either input is not a number.
Problem 2 — Elevator Weight Safety Checker
Function Name Must be: isElevatorSafe
A smart elevator has a maximum safe weight limit of 400 kg. Given an array of people's weights, return true if the total weight is 400 kg or less, otherwise false. Return 'Invalid' if the input is not an array.
Problem 3 — AI Token Cost Calculator
Function Name Must be: calculateAiCost
PromptPal provides 500 free tokens daily. Every additional 100 tokens costs 5 Taka. Return the total cost. Return 'Invalid' if the input is not a number or is negative.
Problem 4 — Top Rated Restaurant Finder
Function Name Must be: topRatedRestaurant
Given an array of restaurant objects containing name and rating, return the highest-rated restaurant's name in uppercase. Return 'Invalid' if the input is not an array or is empty.
Problem 5 — Debugging Challenge: API Response Time Monitor
Function Name Must be: averageResponseTime
Fix all bugs in the provided function. It should return the average response time. Also return 'Invalid' if the input is not an array, is empty, or contains any non-number.
